Vue Product Showcase

Proyecto del Módulo 7 - Desarrollo de aplicaciones Front-End con Vue.

## Instalación

```bash
npm install
```

## Ejecutar

```bash
npm run serve
```

Luego abrir http://localhost:8080

## Tecnologías

- Vue 3
- Vuex
- Vuetify
- Vue Test Utils
- Jest
- Cypress
- Fake Store API

## Funciones

- Catálogo de productos
- Filtro por categoría
- Favoritos
- Estado centralizado con Vuex
- Manejo de carga y error
- Tema claro y oscuro
- Diseño responsive
